# Siyu Lin — Portfolio

An editorial research and visual portfolio for Siyu Lin (QFOI), inspired by
quiet architecture, natural materials, and the rhythm of a private archive.

## Local development

Requires Node.js `>=22.13.0`.

```bash
npm install
npm run dev
```

Build the production site with `npm run build`.

The photographs in `public/images/study-*.jpg` are layout placeholders from
Unsplash and should be replaced with Siyu's personal work before the final
public launch.
